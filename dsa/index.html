Data structures and algorithms, as patterns.

The 154 patterns behind the questions Google asks, each with a short video that runs the real algorithm on one example, step by step.

How to read these notes

Google's DSA interview questions repeat a small number of ideas. These notes list every one of those ideas as a pattern: a one-line idea, the invariant the code keeps true, when to reach for it, and the Google-tagged LeetCode problems it solves. The source is the public LeetCode company-tag export: 2,324 Google-tagged problems, of which 784 are mapped here across 27 topics.

Every pattern has a 42 s video on average (108 minutes in all): a title card, the algorithm run on one small input with a caption per step and the state on screen, then a recap of the invariant, the complexity and the problems. The steps are also written out under each video. Read a topic top to bottom, or search the sidebar for a problem name you have been asked. The sidebar ticks the patterns you have finished, in this browser only.

Difficulty colours and frequencies come from LeetCode; "last 6 months" marks problems reported in the most recent window of the export.
