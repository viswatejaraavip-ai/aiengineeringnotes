Retrieval, fine-tuning and evaluation — explained in plain English, with the real numbers, including the experiments that didn't work.

How to read these notes

The notes are grouped by what they assume. Core concepts are the ideas every retrieval system is built on. Chunking patterns apply them to real corpora and to the things that go wrong when a chunker changes. Security covers what changes once an index holds documents not every user may read. Build breakdowns are two systems built end to end, with the measurements.

Read top to bottom if you are new to retrieval. Each page ends with a link to the next one in that order, and the sidebar ticks the pages you have finished, in this browser only. If you already build these systems, jump to the group you need; every note stands on its own.

Projects

The systems the build breakdowns describe, with live demos and source.

Telugu Purana RAG

Grounded Telugu answers over 17 Puranas that exist only in Sanskrit. A generated Telugu chapter-card layer makes the search same-language; the Sanskrit verses go to the model; every quoted sloka is verified word for word and the meaning is translated on demand.

2,809chapters carded, 141k Sanskrit verses
0.90recall@10 on 96 Telugu questions
0.945faithfulness, LLM judge (5 answers)
2.8¢per chapter card via the Batches API

Telugu Bhagavad Gita RAG

Grounded question answering over 699 verses in Telugu. Every quotation is verified word for word against the source verse, and the system refuses rather than answering from the model's memory.
